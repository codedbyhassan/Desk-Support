# Code of Conduct

## Our commitment

We want Desk-Support to be a welcoming, constructive and professional project for everyone who contributes, reports problems, reviews code or participates in project discussions.

## Expected behaviour

Participants are expected to:

- Be respectful and professional.
- Assume good intent while still addressing real problems directly.
- Give actionable, technical feedback.
- Welcome different levels of experience and perspectives.
- Focus criticism on the work rather than the person.
- Respect project maintainers, contributors and users.

## Unacceptable behaviour

The following behaviour is not acceptable:

- Harassment, discrimination or personal attacks.
- Threats or intimidation.
- Deliberate disruption of project discussions or development.
- Publishing private or sensitive information without permission.
- Trolling, insulting or deliberately inflammatory behaviour.
- Any other conduct that would make participation unsafe or unreasonable for others.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions or take other appropriate action when behaviour violates this Code of Conduct.

Serious or repeated violations may result in a participant being excluded from the project.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the project maintainer rather than escalating it publicly.

For security vulnerabilities, use the process described in `SECURITY.md` instead of a public issue.

## Scope

This Code of Conduct applies to project spaces and interactions related to Desk-Support, including issues, pull requests, reviews and other official project channels.

Thank you for helping keep Desk-Support focused, useful and respectful.
